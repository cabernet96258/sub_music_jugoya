# じゅうごやさんの もちつき リズムづくり

小学3年生の音楽「十五夜さんのもちつき」で使う、リズム作成支援ツールです。
Chromebook のブラウザで開くだけで使えます（`index.html` 1ファイルで完結し、外部ライブラリは使っていません）。

## 使い方

- 下の「おんぷカード」を、歌詞の下の帯へドラッグして置きます（2/4拍子・8小節）。
  - カードは八分音符1マス単位で吸着します。小節線をまたぐ位置では赤く光り、置けません。
  - 置いてあるカードの上に置くと上書きします。帯の外（ゴミ箱など）へドラッグすると消えます。
  - 同じ小節で八分音符が隣り合うと、左から順に2つずつ二連八分音符（連桁）で表示されます。
- 帯の上のミニマップをクリックすると、その小節へ移動します。
- ▶ さいせい：「3, 2, 1, はい！」のカウントのあと、帯が流れます。バーに重なった音符がポコッと大きくなります。
- ❚❚ いちじていし → ▶ つづきから：止めた拍から、2拍のカウントを入れて再開します。
- ■ ていし：最初に戻ります。
- 👏 おてほん ON：児童が置いたリズムを、手拍子の音で鳴らします。
- テンポ：60〜120（最初は80）。

作ったリズム・テンポ・おてほんの設定は、その端末のブラウザ（localStorage）に自動で保存されます。

## 公開方法

### GitHub Pages（まずはこちら）

1. リポジトリの Settings → Pages を開きます。
2. Source を「Deploy from a branch」にし、`index.html` が入っているブランチと `/ (root)` を選んで Save を押します。
3. 数分で `https://cabernet96258.github.io/sub_music_jugoya/` が使えるようになります。この URL を Google Classroom などで配布してください。

### 学校のネットワークで github.io が開けない場合

Google Apps Script の Web アプリとして公開できます。手順は [docs/gas.md](docs/gas.md) を見てください。
