# じゅうごやさんの もちつき リズムづくり

小学3年生の音楽「十五夜さんのもちつき」で使う、リズム作成支援ツールです。
Chromebook のブラウザで開くだけで使えます（`index.html` 1ファイルで完結し、外部ライブラリは使っていません）。

## 使い方

- 下の「おんぷカード」を、歌詞の下の帯へドラッグして置きます（2/4拍子・8小節）。
  - カードは八分音符1マス単位で吸着します。小節線をまたぐ位置では赤く光り、置けません。
  - 置いてあるカードの上に置くと上書きします。帯の外（ゴミ箱など）へドラッグすると消えます。
  - 同じ小節で八分音符が隣り合うと、左から順に2つずつ二連八分音符（連桁）で表示されます。
- 帯の上のミニマップをクリックすると、その小節へ移動します。
- 📷 リズムを コピー：作ったリズム全体（4小節×2段・歌詞つき）を画像にしてコピーします。ロイロノートなどで Ctrl + V で貼り付けられます。コピーできない環境では PNG 画像をダウンロードします。
- ▶ さいせい：「3, 2, 1, はい！」のカウントのあと、帯が流れます。バーに重なった音符はポコッと大きくなり、休符はキュッと小さくなって休みのあいだ薄く表示されます。
- ❚❚ いちじていし → ▶ つづきから：止めた拍から、2拍のカウントを入れて再開します。
- ■ ていし：最初に戻ります。
- 👏 おてほん ON：児童が置いたリズムを、手拍子の音で鳴らします。
- テンポ：60〜120（最初は80）。
- おと：カウントとテンポを刻む音を選べます（ぽこぽこ・ぴよぴよ・ピコピコ・きらきら・ぺったん・ウッドブロック）。選ぶとためしに鳴ります。

### リズムをうってみよう（点数と☆）

再生中に、バーが音符に重なるタイミングでスペースキーを押します（画面の帯をタップしても同じです）。
採点するのは **おてほん OFF のときだけ** です。おてほん ON のときは、スペースキーで手拍子の音は鳴りますが、判定・点数・☆・結果発表は出ません。
ずれの大きさで判定が出て、点数（100点満点）と☆（最大5つ）が増えていきます。☆は、▶ さいせいで最初から再生するたびにリセットされます。

| 判定 | ずれ | 点 |
|---|---|---|
| 💮 はなまる！ | 0.09秒以内 | 100 |
| ◎ すごい！ | 0.15秒以内 | 80 |
| ○ いいね | 0.21秒以内 | 60 |
| △ おしい | 0.28秒以内 | 40 |
| ✓ ざんねん | たたかなかった | 0 |
| ✓ たたきすぎ | 休符や何もないところでたたいた | −20 |

点数 ＝ もらった点の合計 ÷（音符の数 × 100）。休符はたたく対象になりません。
☆は 20・40・60・80 点で 1〜4 つ、**95 点以上で 5 つ** 光り、光るたびにキランと音が鳴ります。
スペースキーを押すと手拍子の音が鳴ります。
再生中は、音符ごとに「はなまる」になるタイミングの範囲がピンクの帯（上に💮）で表示されます。バーがピンクに光っている間に押せば、はなまるです。帯の幅はテンポによって変わり、判定が済むと消えます。
最後まで演奏すると「けっか はっぴょう！」が出て、ドラムロールのあと☆が1つずつ光り、☆の数と点数を発表します。

### じぶんランキング

画面のいちばん下に、自分の点数ランキング（5位まで）が出ます。おてほん OFF で最後まで演奏したときの点数が記録されます。

- 点数の高い順に並びます。同じ点数なら、テンポが速いほうが上です。
- 1位には👑、2位・3位には🥈🥉、点数に応じた称号（リズムのでんせつ／リズムマスター／リズムの たつじん／リズムの なかま／リズムの みならい／リズムの たまご）が付きます。
- 結果発表で「○いに ランクイン！」「じこベスト こうしん！」（紙吹雪つき）や、「5いまで あと ○てん！」を発表します。新しく入った記録には NEW! が付きます。
- 「ランキングをけす」で消せます（確認あり）。

作ったリズム・テンポ・おと・おてほんの設定とランキングは、その端末のブラウザ（localStorage）に自動で保存されます。

## 公開方法

### GitHub Pages（まずはこちら）

1. リポジトリの Settings → Pages を開きます。
2. Source を「Deploy from a branch」にし、`index.html` が入っているブランチと `/ (root)` を選んで Save を押します。
3. 数分で `https://cabernet96258.github.io/sub_music_jugoya/` が使えるようになります。この URL を Google Classroom などで配布してください。

### 学校のネットワークで github.io が開けない場合

Google Apps Script の Web アプリとして公開できます。手順は [docs/gas.md](docs/gas.md) を見てください。
